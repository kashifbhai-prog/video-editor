Keyboard shortcuts

Edit faster with the keyboard. On a Mac, use ⌘ Cmd wherever this page says Ctrl. Shortcuts are paused while you type in a text box. The list is also in the editor under Settings.

Playback

KeysAction
SpacePlay / pause
← / →Previous / next frame
Shift + ← / →Back / forward one second
Home / EndJump to the start / end
MMute / unmute the preview
FFullscreen preview

Editing

KeysAction
SSplit the selected clip at the playhead
Q / WTrim the selected clip's start / end to the playhead
Delete / BackspaceDelete the selected clips (or the selected track or transition)
Ctrl + CCopy the selected clips
Ctrl + XCut the selected clips
Ctrl + VPaste at the playhead
Ctrl + DDuplicate the selected clips
Ctrl + ZUndo
Ctrl + Y or Ctrl + Shift + ZRedo

Selection

KeysAction
Ctrl + ASelect all clips
Ctrl / Shift + clickAdd or remove a clip from the selection
EscClear the selection, close a dialog or menu
Right-click a clipClip menu with actions and details

Timeline view

KeysAction
= / -Zoom in / out
Ctrl + mouse wheelZoom over the timeline

In the player

ActionResult
Drag a selected layerMove it (corner handles scale, the top handle rotates)
Shift + drag the rotate handleRotate in 15° steps
Double-click a textEdit it in place (Ctrl + Enter to finish)

Project

KeysAction
Ctrl + SSave the project
Ctrl + IImport media
Ctrl + EOpen the export dialog
